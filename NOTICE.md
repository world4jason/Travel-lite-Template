# Attribution

Travel Lite is an open-source static/local-first travel companion inspired by and intended to remain compatible in spirit with the client-side travel workflows of [TREK](https://github.com/liketrek/TREK).

TREK is licensed under GNU AGPL-3.0. When TREK source code is copied or adapted into this repository, keep the original copyright/license notices for the affected code and document the modification here or in the relevant source file.

Travel Lite removes TREK's multi-user/server assumptions and targets static hosting such as GitHub Pages. This project is not affiliated with or endorsed by the TREK maintainers.
